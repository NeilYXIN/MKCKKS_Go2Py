# Changelog

## 0.2.0 (release candidate)

- Added the locked `auditwheel` release dependency used to inspect manylinux
  wheels in the release-candidate workflow.
- Reworked large-artifact fuzz targets to use bounded structure-aware mutation
  instructions, preventing Go fuzz-worker shared-memory overflow without
  shortening fuzz duration or bypassing native payload decoders.
- Reject malformed native polynomial headers before entering the pinned
  upstream decoder, closing a fuzz-discovered panic path while keeping upstream
  source unchanged.
- Scoped the expensive generated-circuit counts to their intended Go and
  Python release steps and raised the uncached Go release-test timeout, avoiding
  duplicate heavy coverage execution without reducing the 400-circuit matrix.
- Corrected the preferred software citation to the MASER publication describing
  the Python wrapper while retaining the upstream KKLSS algorithm citation as a
  separate provenance reference.
- Raised observed Go bridge-core coverage above 95% with focused artifact
  validation and failure-atomicity tests; CI enforces a 93% maintenance floor.
- Made release-candidate versioning derive directly from `pyproject.toml`.
- Pinned every release-candidate artifact and report to one resolved commit and
  generated checksums against the filenames published by GitHub Releases.
- Removed machine-specific benchmark output from source control and release
  artifacts; release-relevant reports are generated by the manual workflow.
- Reject fractional/Boolean rotations, invalid ABI flags, non-finite native
  inputs, unsafe rescale thresholds, incompatible scales, and exhausted-level
  multiplication before entering upstream code.
- Removed the public Python `hoisted` Boolean; composite rotations now always
  use the safe compositional upstream path and zero rotation is a keyless copy.
- Added validated/expert input policies, hard resource ceilings, canonical
  native metadata checks, close/use leasing, and synchronous secret cleanup.
- Added direct-upstream differential tests for both presets, formula-based
  precision reports, complex property/metamorphic tests, structured fuzz
  targets, concurrent worker/race tests, and a full operational C ABI harness.
- Added conservative magnitude/error/range tracking to native objects and
  serialization, with sticky correctness status and a one-time warning when a
  cascaded circuit leaves the tested numerical range.
- Added 400 deterministic release circuits, full ordered-operation-pair
  coverage, multi-chunk differential chains, repeated-squaring range probes,
  oracle comparator self-tests, and per-operation C decryption checks.
- Fixed scalar broadcasting so unused chunk padding stays zero under later
  rotations, and converted unsupported lower-level conjugation from an
  upstream panic into a documented `LevelError`.
- Froze Python/native serialization envelope 1.0 and added the first-release
  compatibility bundle generator.
- Corrected the direct-Go benchmark, separated release distributions from
  reports, and reduced GitHub automation to pull-request CI plus a manually
  dispatched draft-prerelease workflow.

## 0.1.0 - 2026-08-06

- Replaced coefficient-copying ctypes structures with an opaque versioned ABI.
- Restored and integrity-locked the pinned upstream Go implementation.
- Added NumPy real/complex arrays, chunking, full evaluator operations,
  collective decryption, explicit serialization, typed errors, and lifecycle
  safety.
- Added uv/scikit-build packaging, tests, documentation, licensing provenance,
  and project governance.

The 0.x API and artifact formats may change before 1.0.
